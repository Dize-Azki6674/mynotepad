# mynotepad

## 概要

Qt Widgetsを使用して開発したシンプルなメモ帳アプリケーションです。

C++によるGUIアプリケーションの設計・実装を学習することを目的としています。

## 特徴

- Qt Widgetsを使用したGUI
- テキストファイルの新規作成・読み込み・編集
- 編集内容の上書き保存・名前を付けて保存
- コピー・切り取り・貼り付け
- 未保存の編集内容がある場合の終了確認

## 動作環境

- OS：Windows
- 言語：C++23
- GUIライブラリ：Qt 6.12.0
- ビルドシステム：CMake
- コンパイラ：MSVC 2022

## ビルド

本プロジェクトはCMakeを使用してビルドします。

Qt 6.12.0および対応するMSVC用コンポーネントをインストールした環境で、Qt CreatorからCMakeプロジェクトを開き、適切なキットを選択してビルドしてください。

## 実装について

本プロジェクトでは、GUIアプリケーションの開発を主な目的としています。

- Qt Widgetsを利用したGUIの構築
- シグナル・スロットによるイベント処理
- ファイル入出力
- ダイアログを利用したユーザーとの対話
- CMakeによるビルド管理

## 制限事項

- Windows向けの開発を想定しています。
- テキスト編集に特化したシンプルなメモ帳であり、高度な編集機能は備えていません。

## 開発状況

今後は不具合修正やリファクタリングを除き、大きな機能追加の予定はありません。
